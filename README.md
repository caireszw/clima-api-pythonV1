# clima-api-pythonV1
Projeto em Python para consumo de API climática utilizando Requests e manipulação de JSON.

## Funcionalidades

- Consulta de clima por cidade
- Exibição de:
  - Temperatura
  - Condição climática
  - Estado/região
  - Última atualização
- Salvamento da resposta da API em arquivo JSON
- Manipulação de dados JSON

## Tecnologias utilizadas

- Python
- Requests
- JSON

## Como executar

Clone o repositório:

```bash
git clone LINK_DO_REPOSITORIO
```

Instale as dependências:

```bash
pip install requests
```

Execute o projeto:

```bash
python main.py
```

## Exemplo de saída

```plaintext
A cidade de São Paulo localizada no estado de São Paulo está com Parcialmente nublado, na temperatura atual de 19°C
```

## Objetivo do projeto

Projeto criado com foco em aprendizado de:
- APIs REST
- Requisições HTTP
- Manipulação de JSON
- Consumo de APIs externas em Python
